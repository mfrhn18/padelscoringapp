# Padel Round v1.0.7-hotfix-1

Fixes:
- Shared URL player names now correctly open the read-only player statistics modal.
- Shared player statistics modal includes match history, best partners, and a Create my result image action.
- Shared URL Share button now offers Result URL or Create result image.
- Player Spotlight template now includes a player selector so any player can be selected.
- Player Spotlight automatically defaults to the current top-ranked player when opened generally.
- Player Spotlight's two comparison players are selected by closest final ranking, following the agreed 1st→2nd+3rd, 2nd→1st+3rd, 3rd→1st+2nd behavior.
- Existing v1.0.6-hotfix-4 functionality preserved.
